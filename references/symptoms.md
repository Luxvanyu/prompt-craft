# 症状 → 改哪句（诊断索引）

出图不对时，**不要重写整份提示词**。先在这里找到症状，按「先量什么」确认，然后只改那一句。

用法：`probe.py` 拿到数值 → 在本表找症状 → 改指出的那一句 → 重跑 lint → 只重出一张。

## A 人物

| 症状 | 先量什么 | 改哪一句 | 规则 |
|---|---|---|---|
| **人太小 / 太大** | 量头顶 y 到鞋底 y 的像素高 ÷ 画高 | 加/改「头顶比某件同深度物体的哪条边低多少」，并让那条边在画面上水平贯穿 | G54 |
| 放大 1.5–2.5 倍，改距离没用 | 同上 | 删掉「二十步/三十五步」这类纯距离句——它对人物大小**零作用**（118：20 步 46.4%、35 步 45.4%） | G46 |
| 给的比例句完全无效 | — | 比例句永远只是安全带，真正起作用的是对位句 | G21 / G54 |
| **人不在画面里** | 别用 sd／滑窗去证伪（暗部必然假阴性） | 检查三句是否齐全：① 在实体之间而不是空处；② 整个人在画框内 + 上下有余量；③ 头顶对齐画内某物 | G51 |
| 人被并进别的块 | grep 其他 item 里有没有 `the girl / she / her` | 人物只在自己的 character 块里被描述 | G49 |
| 人贴着光斑 → 被吃掉 | — | 检查是否「bbox 落在最亮区 + caption 说她站在阴影里」，二者只能留一个 | G9 |
| **朝向反了 / 三成背面** | — | 写死「看得见哪只眼、哪半边脸」，加否定「我们不在她背后」；不要写 `three quarters turned away` | B 组 |
| 手变成爪子 / 融臂 | — | 手放到身体近侧可见位置，绝不写背后撑地；JSON 里 hands 块只框手 | m（47 号） |
| 手势出成剪刀手 | — | 禁用「食指中指竖起、其余收进掌心」这个配方；改成一指一指写长度方向 | 69 号 |
| 表情读不出来 | — | 不写状态词，写肌肉形变：嘴角平不平、眉毛聚没聚、眉心有没有竖纹 | G3 |

## B 明度与曝光

| 症状 | 先量什么 | 改哪一句 | 规则 |
|---|---|---|---|
| **整体发灰** | `mean` 0.38–0.55、`nw` < 0.03 | 分配暗部**面积**，不是调整形容词 | 关 8 |
| **亮部烧白** | `nw` > 0.05、`sat lit` < 0.10 | 删 `pure white / overexposed / blown to`，改关系句：「亮面比暗面亮一档，且保留全部颜色」 | 关 8 |
| 写「不是白，是浅蓝灰」反而更亮 | — | 否定 + 浅色 = 更亮。压亮度只能靠暗部面积（118v2 mean .719） | 118v2 |
| **整体埋黑** | `mean` < 0.30、`dark` > 0.39 | 把暗块 bbox 面积减半；「一个大的暗」≠「三分之一的暗」 | 107 / 108 |
| **挤在中调** | `mid` > 0.75 | 写三档各占多少：暗 ≥30%、中 ~40%、亮 ≤12% | G43 |
| 写了 `Mid tone overall` 反而全中调 | — | 这句是总指令，必须紧跟黑锚点 + 亮部点名带色 | G43 |
| 高调图整体飘 | — | G4：写「全图只有三处接近黑，具体是哪里」，措辞用 `three darks` / `the deepest black` | G4 |
| 低 key 不够暗 | `dark` < 0.30 | `low key` 是词不是数量；写暗部面积（上限约 60–65%） | G35 |
| 想故意过曝 | — | `lint.py --intent blown` 放行，但仍要写「哪里烧掉、哪里留颜色」 | 121 |

## C 色彩

| 症状 | 先量什么 | 改哪一句 | 规则 |
|---|---|---|---|
| **整张没颜色** | `sat` < 0.16 | 色相必须落在**被照亮的大面积**上；写在暗部/小物件等于没写 | G9 |
| 写了颜色但落在暗处 | 同上 | 把那个色从暗部搬到亮面 | G9 |
| 中性色吃掉画面 | 关 9：中性词 > 色相词 | 用 `ochre / amber / pink / tan` 替换 `grey / pale / white`（`peach / rose / apricot / cream` 不在词表里，模型也不当色相） | 121 |
| 主色跑偏 | 色相差 > 30° | 换一个同族但更基础的颜色名 | verify.py |
| lint 报「中性色多于色相」但明明写了颜色 | `grep` summary 里的 `pale` / `grey` / `near white` | lint 只统计 `summary.caption` 且按子串计数：`grey green` 同时算 grey 和 green。把大面颜色改成不带修饰的纯色相词（`sage green celadon` / `deep indigo black`），`pale` 只留给小物件 | 关 9 |
| 「全图统一成一支色」和「某物是唯一冷色」并存 | — | 例外必须显式排除：`apart from X, every surface bleaches to...` | G5 |
| 低饱和但不知是不是事故 | — | 先判断：该有色差的地方（亮/暗、不同材质）有没有色差 | G7 |

## D 光

| 症状 | 先量什么 | 改哪一句 | 规则 |
|---|---|---|---|
| **灯被画进画面** | grep `tube / lamp / bulb / fixture / strip light / diffuser` | 光源不许给名词；只写落点 + 衰减 + 未照亮区 | G41 |
| 硬光变阴天 | `strong` < 0.10 | 写边缘硬度：`cut like a blade, with no gradient at all` | G6 |
| 影子方向和光矛盾 | — | 影子是被照物的后果，先定光再写影；低机位的光会让影子全部反 | 107 |
| 光斑位置错 | 6×6 grid 最亮格 | 面积词是几何指令（`fills the top quarter` 会盖天花板）；写「顶部六分之一的一条窄横带」 | B9 |
| 光柱凭空出现 | — | 场景自带先验不能否认：写了画外上方有光就一定画光柱 → 改写成「它照到哪里」 | G27 |
| 漏光/眩光/鬼影变成实体 | — | 逐项否认它是物体 + 写它跨深度而值不变 + 边界只是值的变化 | G55 |

## 通用判定阈值（probe 输出直接对着看）

| 项 | 合格区间 | 超了会怎样 |
|---|---|---|
| `mean` | 0.38–0.55 | 低 = 埋黑，高 = 发灰发白 |
| `dark` | ≥ 0.08（低 key 要 0.30+） | 不够 = 画面飘 |
| `mid` | < 0.75 | 超 = 没有明暗对比 |
| `nw` | < 0.03 | 超 = 烧白，亮部失去颜色 |
| `p1` | < 0.10 | 超 = 黑位抬起，发灰 |
| `sat` | ≥ 0.16 | 不够 = 整张没颜色 |
| `lit − shadow` | ≥ 0.45 为理想 | 反转 = 亮部比暗部还淡，气氛全错（107 是合法例外） |
| `soft` | < 0.65 | 超 = 硬光退化成阴天（soft 是 1 − strong，两者恒和 1） |
| `strong` | > 0.10 或 soft < 0.65 | 都低 = 没有硬边 |
| `flat` | 0.35–0.55 | 超 = 大范围 bloom/雾；低 = 全图硬边 |

**注意**：`lit / shadow` 是**饱和度的平均**，不是明度。判断明度用 `mean / dark / mid / bright`。
