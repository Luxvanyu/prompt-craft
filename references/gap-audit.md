## 二、没测过的（缺口，按优先级）

### P0 —— 今天暴露的，必须补

**1. 介质成像（倒影 / 镜子 / 玻璃 / 水 / 雾 / 雨窗）**
77 号实测：写了「四分之五的画面是水洼的倒影」，出图仍然是「天在上、路在下」的正景。
原因：模型的世界先验「天在上」强于「这是倒影」这句话。
→ 需要验证的写法：让画面里出现**物理上只能倒置的证据**（水面横线穿过画面中部、树冠长在画面下缘、
人在画面下方倒着走），而不是陈述「这是一面镜子」。

**2. 介质表面痕迹的归属**
77 号把「水面上的尘埃与花粉」写进了天空块，出图变成**天上的星点**。
→ 规则：介质上的痕迹必须写成独立块，并显式否认它在内容上
（`these specks lie on the water and not in the sky`）。

**3. 剪影照的「暗部极饱和」**
参考暗部 sat 0.619、出图 0.264。深蓝天本身是「暗且最饱和」的东西，我只写了明度没写饱和度归属。
→ 规则：剪影图必须写「全图最饱和的东西是那块暗的天」，否则暗部会被拉灰。

**4. 剪影的边缘硬度**
参考 soft 0.465、出图 0.640。剪影照靠「叶子边缘是硬边、内部没有层次」立住，我只写了「没有受光面」。
→ 规则同 G6，但要延伸到「暗形内部的零层次」。

### P1 —— 通用 skill 一定会遇到

**5. 无人画面**（空景、静物、建筑、器物）
现在所有构图规则都以「人物比例尺」为锚（G8），没有人的图完全没有体系：
主体怎么定、尺度怎么给、视觉重心放哪。

**6. 多人关系**（接触、对视、高低差、成群）
只测过两人并排走（41 号）。没测过：拥抱/牵手/托举/背人/一群人/一人对多人。
多主体的 bbox 冲突、身份漂移、接触点写法都未验证。

**7. 动态与快门**
长曝光只测了星轨。没测：运动模糊、车灯拖线、慢门水、连拍多影、频闪、
奔跑/跳跃/摔倒的「单帧物理」。

**8. 混合光源与色温分裂**
只测过「室内暖 + 窗外冷」的暗示。没测：钨丝 + 荧光 + 霓虹同框、
彩色光打在皮肤上、屏幕光照脸、投影仪、警灯、舞台顶光。

**9. 极端机位**
正俯视（top-down）、贴地仰视、微距、超长焦压缩、鸟瞰。B 组只覆盖到「俯拍 60 度」。

**10. 材质专测**
金属（拉丝/镜面/氧化）、玻璃（透射+反射叠加）、皮肤（油/汗/毛孔）、毛发（湿/静电）、
织物（厚薄/透光/褶皱）、粉尘、半透明（叶脉/薄纱/冰）。

**11. 天气与大气**
雨的三种写法（雨丝/雨滴砸地/雨幕）、雪、雾、风沙、热浪扭曲、雨后蒸汽、逆光尘埃（丁达尔）。

**12. 画面内真实文字**
技能目前默认零文字。通用 skill 必须能开字：招牌、海报、书页、手写便条、
以及「文字作为构图元素」的排版写法。

### P2 —— 实验性 / 风格跨度

**13. 风格族**：黑白、双色/单色、报纸网点、8mm、色分离错位印刷、像素、
复古印刷网点、手绘线稿、漫画分格。

**14. 画幅族**：21:9、1:1、9:16、2:1 横幅。现在只覆盖 3:2 / 4:3 / 1.75:1 / 2:3。

**15. 「有意的错误美学」**：故意过曝、欠曝、失焦、歪、漏光、刮片、晕影、构图失衡。
这一类与「关 8 曝光」直接冲突，需要一套「这是有意的」豁免写法。

**16. 极小 / 极大主体**：主体小到只占画面 1/20（不是人，是一枚硬币/一只鸟/一个烟头）；
主体大到塞满画面（一张脸、一堵墙、一片织物）。

**17. 序列一致性**：同一场景同一角色连出 3–5 张，要求「像同一天拍的」。
这需要「可复用的固定短语块」，是通用 skill 的核心价值之一，完全没测。

## 三、建议的测试顺序（每 1–2 条一个主题，测完立刻入库）

1. 介质成像三连：水洼倒影（重做）/ 雨窗 / 玻璃反光叠加透射 — 补 P0
2. 无人空景两条：一间空房间的早晨 / 一件静物（桌上一杯冷水）
3. 多人接触两条：两人并肩坐着手搭在对方肩上 / 一人背着另一人
4. 动态两条：雨夜车灯拖线 / 奔跑中单脚离地
5. 混合光两条：便利店冷白 + 街灯钠黄 / 屏幕光照脸
6. 极端机位两条：正俯视一张 / 贴地仰视一张
7. 材质四连（一张图里四种材质各占一块）：金属 / 玻璃 / 湿布 / 皮肤
8. 文字两张：招牌 / 手写便条（验证 text 块与透视）
9. 风格三连：黑白 / 报纸网点 / 8mm
10. 序列一致性：同一场景三张
